# 🎉 ระบบเว็บแอปพลิเคชันสายรหัส (Stat Lineage System)

ระบบสำหรับจัดกิจกรรมสายรหัสและบัดดี้ภายในภาควิชาสถิติ (Stat)
แพลตฟอร์มที่เชื่อมโยงพี่รหัสและน้องรหัสเข้าด้วยกันผ่านระบบเกม การใบ้คำ แชทเรียลไทม์ และระบบบัดดี้

## 👥 คู่มือการใช้งานแบ่งตามบทบาท (Roles)

### 👶 แดชบอร์ดน้องรหัส (Junior)
หน้าต่างสำหรับน้องรหัสเพื่อติดตามหาพี่รหัสของตนเองผ่านคำใบ้และทำกิจกรรมต่างๆ:
- **ข้อมูลส่วนตัว:** ดูข้อมูลของตนเอง และแก้ไข "สิ่งที่ชอบ (Favorites)" ได้
- **แชทสายรหัส (Lineage Chat):** พูดคุยกับพี่รหัส (และเพื่อนๆ น้องรหัสในสายเดียวกัน) โดยระบบจะซ่อนชื่อจริงและรูปของพี่รหัสไว้จนกว่าจะถึงเวลาเฉลย
- **ระบบคำใบ้ (Hints):** ดูคำใบ้ที่พี่รหัสส่งมาให้ เพื่อใช้ประกอบการตามหาตัวพี่รหัส
- **ระบบทายพี่รหัส (Guessing):** เมื่อแอดมินเปิดระบบทาย น้องสามารถเลือกทายชื่อและสาขาของพี่รหัส หากทายถูกจะมีเอฟเฟกต์เฉลิมฉลอง (การตรวจคำตอบทำผ่าน Backend เพื่อความปลอดภัย)
- **วงล้อสุ่มบัดดี้ (Roulette):** สำหรับสุ่มหาบัดดี้ในครั้งแรกที่เข้าสู่ระบบ
- **ระบบบัดดี้ (Buddy):** แชทพูดคุยแบบไม่เปิดเผยตัวตนกับบัดดี้ (พี่รหัสที่ดูแลเรา) และสามารถดูไอจีของบัดดี้ได้
- **แชทรวม (Global Chat):** ห้องแชทส่วนรวมสำหรับพูดคุยกับทุกคนในภาควิชา
- **รับดาวประจำวัน (Daily Login):** ล็อกอินต่อเนื่องทุกวันเพื่อรับดาวสะสม

### 🦁 แดชบอร์ดพี่รหัส (Senior)
หน้าต่างสำหรับพี่รหัสในการดูแลน้องรหัสและส่งคำใบ้:
- **ข้อมูลน้องรหัส:** ดูรายชื่อน้องรหัสในสายทั้งหมด พร้อมแสดงสาขา สิ่งที่ชอบ และไอจี เพื่อช่วยให้พี่เทคแคร์น้องได้ง่ายขึ้น
- **ระบบจัดการคำใบ้ (Hint Management):** พี่รหัสสามารถพิมพ์เพิ่มคำใบ้ใหม่ๆ ให้น้อง หรือลบคำใบ้เดิมทิ้งได้
- **คำใบ้พิเศษ (Special Hint):** หากแอดมินเปิดอนุญาต พี่รหัสสามารถใช้ "ดาวสะสม" เพื่อแลกกับการเปิดคำใบ้พิเศษให้น้องรหัสเห็นได้
- **แชทสายรหัส (Lineage Chat):** คุยกับน้องๆ ในสายรหัส
- **ระบบบัดดี้ (Buddy):** คุยกับน้องบัดดี้ที่ตนเองสุ่มได้แบบไม่เปิดเผยตัวตน (น้องจะไม่รู้ว่าเราคือใคร)
- **แชทรวม (Global Chat):** ห้องแชทรวมสำหรับทุกคน

### 👑 แดชบอร์ดผู้ดูแลระบบ (Admin)
ควบคุมระบบทั้งหมดของงานผ่าน Admin Panel:
- **ระบบตั้งค่า (Configs):** 
  - เปิด/ปิด การให้พี่รหัสใช้ดาวเปิดคำใบ้พิเศษ
  - เปิด/ปิด ระบบทายพี่รหัสสำหรับน้อง
  - เปิด/ปิด แชทรวม (Global Chat)
- **การจัดการสายรหัส (Lineage Management):** กดปุ่ม "เฉลยสายรหัส" (Reveal) ให้รายบุคคล หรือกด "เฉลยทั้งหมด"
- **การจัดการแชท & ดาว (Airdrop):** แอดมินสามารถส่ง Airdrop แจกดาวในหน้าแชทรวมให้ผู้ใช้งานกดรับได้ตามโควต้า
- **ระบบฐานข้อมูลผู้ใช้:** ค้นหาชื่อนิสิต, แก้ไขข้อมูลส่วนตัว (เช่น ไอจี, ดาวสะสม), และกดปุ่ม Log in as เพื่อจำลองเป็นนิสิตคนนั้นๆ ได้
- **ระบบรีเซ็ตฐานข้อมูล:** ล้างข้อมูลทั้งหมดและอิมพอร์ตข้อมูลตั้งต้นใหม่
- **รับรายงานปัญหา (Report):** เมื่อผู้ใช้กดปุ่มรายงานปัญหาทางหน้าเว็บ แอดมินจะได้รับอีเมลแจ้งเตือนพร้อมรายละเอียดปัญหาโดยอัตโนมัติ

## ✨ ฟีเจอร์เด่นอื่นๆ ของระบบ

- **ระบบแชท Real-time (WebSocket):** ใช้ Cloudflare Durable Objects ทำให้แชทไหลลื่น ไม่ต้องรีเฟรชหน้าเว็บ พร้อมระบบ Read Receipt (อ่านแล้ว) และ Reaction ตอบกลับข้อความ
- **ความปลอดภัยระดับ Backend (Security & Auth):** 
  - การทายพี่รหัส ตรวจสอบความถูกต้องบนเซิร์ฟเวอร์เท่านั้น (ป้องกันน้องรหัสเปิด DevTools ดูเฉลย)
  - Redaction Data: หากยังไม่เฉลยสายรหัส ข้อมูลความลับของพี่รหัสจะถูกลบออกตั้งแต่ฝั่ง API ก่อนส่งไปถึงเบราว์เซอร์
- **ระบบสะสมดาว (Star System) & Streak:** ล็อกอินเข้าสู่ระบบทุกวันเพื่อรับดาว และมีโบนัสพิเศษหากล็อกอินต่อเนื่อง นำดาวไปใช้ทำกิจกรรม
- **รายงานปัญหาอัตโนมัติ (Email Notifications):** ทำงานร่วมกับ API ของ Resend เพื่อส่งอีเมลหาแอดมินทันทีที่มีผู้ส่งเรื่องรายงานปัญหา

## 📂 โครงสร้างโปรเจกต์ (ภาพรวม)

- `index.html` / `style.css`: ไฟล์หน้าต่างแสดงผลหลัก (UI/UX)
- `app.js`: จัดการ Logic ส่วนใหญ่ในฝั่งผู้ใช้งาน เช่น การสลับหน้า, ระบบ UI, จัดการฟอร์ม, อัปเดต DOM
- `app_ws.js`: จัดการระบบ Real-time (WebSocket) สำหรับระบบแชท แอร์ดรอป และการตั้งค่าสด
- `database.js`: ไฟล์เก็บข้อมูลตั้งต้น (Initial Data) และข้อมูลสายรหัสเริ่มต้น
- `functions/api/`: โฟลเดอร์รวม REST API ทั้งหมดรันบน Cloudflare (เช่น /api/login, /api/guess)
- `chat-worker/`: โฟลเดอร์สำหรับจัดการ Durable Objects (เซิร์ฟเวอร์แชท WebSocket)
- `schema.sql`: โครงสร้างฐานข้อมูล D1
- `wrangler.toml`: การตั้งค่าและตัวแปร Environment Variables สำหรับ Cloudflare

## 🚀 การอัปเดตและ Deploy ขึ้นเซิร์ฟเวอร์

หากมีการแก้ไขโค้ด สามารถใช้คำสั่งของ Wrangler เพื่ออัปเดตระบบได้ทันที:

```bash
# 1. อัปเดตฝั่งหน้าเว็บและ REST API (Pages)
npx wrangler pages deploy . --project-name stat-lineage-app

# 2. อัปเดตฝั่งเซิร์ฟเวอร์แชท (Worker/Durable Object) กรณีที่มีการแก้ไขในโฟลเดอร์ chat-worker
cd chat-worker
npx wrangler deploy
```
